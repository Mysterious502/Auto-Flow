# Security Policy

## Supported versions

Security reports are accepted for the latest version of Auto Flow. The current version is **1.0.1**.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request.

If GitHub's private vulnerability reporting is enabled for this repository, use the repository's **Security** tab and select **Report a vulnerability** to submit a private report. If that option is unavailable, contact the repository maintainers privately through their GitHub profile before sharing technical details.

Include as much of the following as you safely can:

- A clear description of the suspected vulnerability and its potential impact.
- The affected version, browser, and operating system.
- Reproduction steps or a minimal proof of concept.
- Any relevant page or permission context.

Do not include real prompts, credentials, session cookies, personal information, or other sensitive data in a report. Please allow maintainers reasonable time to investigate and prepare a fix before publicly disclosing the issue.

## Scope

Please report security issues in the Auto Flow extension itself, including unsafe handling of scheduled task data, unintended access or injection behavior, and problems related to its declared permissions.

Issues in Claude, ChatGPT, Gemini, Chrome, or other third-party products should be reported to their respective maintainers. Auto Flow cannot guarantee the security or availability of third-party websites.

# Contributing to Auto Flow

Thanks for your interest in contributing. Bug reports, ideas, and pull requests are welcome.

## Before you open an issue

- Search existing issues to check whether the problem has already been reported.
- For a bug report, include the browser and version, the affected website, steps to reproduce, and what you expected versus what happened.
- Do not include private AI conversations, prompts, credentials, cookies, or other sensitive information.
- For security vulnerabilities, do not open a public issue. Follow the private reporting instructions in [SECURITY.md](./SECURITY.md).

## Pull requests

1. Fork the repository and create a branch for your change.
2. Keep the change focused and explain the reason for it in the pull request.
3. Test the extension in a Chromium-based browser by loading the project folder through `chrome://extensions` with Developer mode enabled.
4. For changes to prompt automation, test only with a non-sensitive prompt on the relevant website.
5. Update the README if the change affects installation, usage, supported websites, permissions, or known limitations.
6. Open a pull request and describe the changes and the checks you performed.

There is currently no automated test or build command configured in this repository. Please report manual checks accurately and do not claim automated tests passed unless such tests have been added and run.
